## About the Game

**MagicShot Roulette**는 벅샷룰렛의 규칙을 턴제 RPG 형식으로 변형한 콘솔 게임입니다. 플레이어는 현재 약실의 탄이 실탄인지 가탄인지에 따라 자신을 쏠지, 적을 쏠지, 아이템을 사용할지 선택합니다. 가탄으로 자신을 쏘면 턴을 유지하고, 실탄으로 적을 쏘면 공격 기회를 이어갈 수 있으며, 반대로 잘못된 선택을 하면 턴이 종료되고 몬스터의 공격을 받습니다. 전투 외에도 휴식, 미지 이벤트, 승리 보상, 아이템 획득을 통해 HP, MP, 인벤토리 슬롯을 강화하며 현재 버전에서는 1층과 2층까지 플레이할 수 있습니다.

## Features

- **탄 상태 기반 전투**: 실탄 / 가탄 여부와 총구 방향에 따라 결과 분기
- **턴제 게임 루프**: 플레이어 선택 → 결과 처리 → 몬스터 턴 구조 구현
- **아이템 시스템**: 약실 확인, 탄 제거, 데미지 증가, 방어, 탄 반전 등 전투 변수 조작
- **성장 구조**: 전투 보상과 맵 이벤트를 통한 HP / MP / 인벤토리 강화
- **콘솔 UI 구현**: 키 입력 기반 선택지 조작과 전투 상태 출력

## Controls

- **↑ / ↓** : 선택지 이동
- **← / →** : 총구 방향 변경
- **Space** : 선택 / 진행
- **Esc** : 게임 종료

## Development Notes

이 프로젝트는 단순한 CLI 과제보다는, 제한된 콘솔 환경 안에서 **명확한 전투 루프와 상태 변화를 가진 게임 구조**를 만드는 데 초점을 두었습니다.  
탄 상태, 총구 방향, 아이템 효과, 턴 유지 여부, 몬스터 행동을 하나의 흐름으로 연결하면서 입력 처리와 결과 분기를 관리했습니다.

초기에는 몬스터도 총기를 사용하는 구조를 고려했지만, 구현 범위와 완성도를 위해 플레이어만 총을 사용하는 방식으로 조정했습니다.  
대신 현재 약실을 중심으로 한 선택과 아이템 활용이 전투의 핵심이 되도록 설계했습니다.
